## To share an existing app

- Node 20+, Git, and a GitHub account with push access.
- A public repository with a committed, pushed Xcode iOS project or workspace.
- An app scheme. Specify `--project` and `--scheme` if detection is ambiguous.

An iPhone is not required. [Preview recording](/guide/product/app-listing/#preview-recording) is optional.

## To try an app

- macOS 14+ and full Xcode, opened once to complete setup.
- Your Apple Account and signing team configured in Xcode.
- Your intended iPhone, unlocked, with Trust and Developer Mode enabled. Use a data cable for initial setup.
- Your approval to run the selected source and build scripts.

Apple provisioning limits, entitlements, and expiration still apply. A public listing or review does not guarantee a compatible or safe build. No coding agent is needed to install someone’s app.

## To create or evolve through intents

[Install and pair Menlo on your iPhone](/guide/start/install-and-onboard/#start-from-scratch), and configure an authenticated coding agent on your Mac. Keep the Mac awake for builds.

Local or bring-your-own coding has no Menlo subscription gate. Managed inference has separate consent and balance requirements.
