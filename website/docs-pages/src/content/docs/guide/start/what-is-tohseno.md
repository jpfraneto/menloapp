---
title: What is menloapp?
description: An app link, a Mac build, and your iPhone.
---

menloapp connects a public GitHub iOS project to an app link.

1. The maker runs `menloapp deploy` and shares the link.
2. The recipient reviews the source and approves a local build.
3. Their Mac builds with Xcode and their Apple signing identity.
4. The app installs on their intended iPhone.

The ordinary link follows the default branch. An exact-version link keeps one repository and commit. Recipients choose updates; a GitHub push does not update an installed app automatically.

You can also [create from an idea](/guide/start/create-an-app/) using a coding agent on your Mac.

Sharing needs no wallet, gas, Claim, or iPhone pairing. Installing requires [Xcode and Apple setup](/guide/start/requirements/).
