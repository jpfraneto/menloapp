menloapp lets you share an iOS app from GitHub. Recipients build it on their own Mac and install it on their iPhone.

- [Share an app](/guide/start/share-an-app/) — publish a link to your GitHub project.
- [Try an app](/guide/start/install-and-onboard/#try-someone-elses-app) — review, build, and install it.
- [Create an app](/guide/start/create-an-app/) — describe what you want to make.

## Quick start: share

In your committed, pushed public GitHub app folder:

```sh
npm i -g menloapp
menloapp deploy
```

Share the returned exact-version link to keep the source commit you deployed. Push to GitHub to make updates available; recipients choose when to install them.
