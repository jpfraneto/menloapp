**Your GitHub app. On their iPhone.** MENLO connects a public GitHub repository to a living app link. A tester reviews a commit, builds and signs it on their own Mac, and tries it on their intended iPhone.

## Deploy once. Push as usual.

The app follows its GitHub default branch. Later pushes appear as updates; testers choose when their Mac builds the next commit. Companion shows how many commits the installed app is behind.

## No gas. No source upload.

GitHub supplies identity, profiles, and version control. MENLO runs a centralized directory and off-chain registration ledger today. Decentralized witnessing is a possible v1/v2 step when it earns its cost.

The package remains named `tohseno`; `menlo` is an alias. The 1.3.0 preview has a direct installer while npm publication and GitHub sign-in setup are completed. [Use the working preview path](/guide/start/install-and-onboard/) or [check current status](/guide/reference/current-status/).

[Try Hello from MENLO](https://tohseno.com/hello-menlo) · [Download MENLO for Mac](https://tohseno.com/download/macos) · [Explore apps](https://tohseno.com/apps).

Apple signing, provisioning, Trust, and Developer Mode still apply. Earlier Registry and Claim documentation describes the retained legacy system, outside the normal GitHub path.
